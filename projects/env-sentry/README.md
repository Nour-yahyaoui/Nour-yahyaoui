# 🛡️ env-sentry — Zero-Dependency `.env` Toolkit

The zero-dependency `.env` toolkit: lint it, diff it, audit it, scan for leaks, generate real secrets — and keep them out of git. Catches `.env` drift, hardcoded secrets, and missing `.gitignore` entries before you commit them.

## ✨ Highlights

- **Lint** — validate `.env` formatting and key coverage against templates
- **Diff** — compare `.env` files across environments
- **Audit** — scan for hardcoded secrets and leaked credentials
- **Generate** — create real, cryptographically secure secrets
- **Zero dependencies** — pure Python, no `pip install` beyond the package itself
- **CI-ready** — exit codes and workflow recipes for automated pipelines
