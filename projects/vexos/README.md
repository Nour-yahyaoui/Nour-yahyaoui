# 🖥️ VexOS Desktop — Live Linux Dev Environment

A live Linux desktop built from Debian trixie for web and software development. Boot one ISO in VirtualBox and you get XFCE, Firefox ESR, Python 3, Node.js with npm, Rust with cargo, gcc, git, and **VexOS DevStudio**: a browser-based IDE with a code editor, a Run button, a live preview, and an AI assistant that uses your own Groq key — which stays on your machine.

## ✨ Highlights

- **Built from source** — the image is made with live-build; every package list is a plain text file in the repo
- **Clean by design** — the live session runs in RAM, so a reboot restores the system to its starting state
- **Ready to code** — compilers, runtimes, and the IDE are already set up when it boots
