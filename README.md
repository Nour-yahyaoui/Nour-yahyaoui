## 👨‍💻 About Me

> *"AI power with the perfect leadership."*

I'm **Nour Yahyaoui**, a full-stack developer from **Tunisia** with **3+ years of freelance and client experience**.

I build beautiful, secure, and scalable applications — from web and mobile to desktop — turning complex problems into elegant solutions.

**My journey:**

I started with Python and web fundamentals, moved through JavaScript, React, and modern full-stack development with Next.js, React Native, and serverless architectures.

Today I'm expanding into **Rust (Actix Web / Axum & native systems)** to build performance-critical backend services and desktop software.

**What I build:**

Production web applications end-to-end (frontend, backend, deployment), developer tools, AI-powered systems, and native software.

Some of my projects include:

- **RustPad** — Zero-dependency Rust desktop studio.
- **VexOS Desktop** — Browser-based Linux desktop environment.
- **nour-code** — Local AI coding agent powered by Ollama.
- **Matjari** — POS system for retail shops.
- **WinterCave** — Latency-focused local text editor.
- **env-sentry** — Environment configuration security CLI.

📌 Each featured project links to its dedicated repository and documentation.
